### Connect

A few lines on the board and your device is online: one object with the device credentials, and the library handles Wi-Fi, TLS and reconnection. Declare a pin as a resource to control it from a dashboard, the REST API or an AI agent, and any value the board computes becomes telemetry you can chart, store and alert on.

Devices speak **[IOTMP](https://github.com/thinger-io/IOTMP)**, our open, lightweight bidirectional protocol. Pick the client for your hardware:

| Platform | Library |
|---|---|
| Arduino (ESP32, ESP8266 and more) | [Arduino-Library](https://github.com/thinger-io/Arduino-Library) · [IOTMP-Arduino](https://github.com/thinger-io/IOTMP-Arduino) |
| ESP-IDF | [IOTMP-ESPIDF](https://github.com/thinger-io/IOTMP-ESPIDF) |
| Zephyr | [IOTMP-Zephyr](https://github.com/thinger-io/IOTMP-Zephyr) |
| Linux (Raspberry Pi, gateways, servers) | [IOTMP-Linux](https://github.com/thinger-io/IOTMP-Linux) |
| Embedded ports | [IOTMP-Embedded](https://github.com/thinger-io/IOTMP-Embedded) |

### Manage, with your AI

Run your fleet by talking to it. Claude, Codex, Cursor or any other MCP client connects through **[thinger-cli](https://github.com/thinger-io/thinger-cli)**, with nothing to install on the devices. You decide what the agent can see and what it can touch.
